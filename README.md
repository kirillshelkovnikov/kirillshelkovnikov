## Запуск программ на C

Нужен GCC или Clang. Например:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic labs/lab01_series.c -o lab01
./lab01

gcc -std=c11 -Wall -Wextra -Wpedantic labs/lab02_array.c -o lab02
./lab02

gcc -std=c11 -Wall -Wextra -Wpedantic exercises/matrix_tasks.c -o matrix_tasks
./matrix_tasks

gcc -std=c11 -Wall -Wextra -Wpedantic projects/transactions.c -o transactions
./transactions projects/sample_transactions.csv
```

> Лабораторные адаптированы по моим учебным отчётам: сохранены задачи и математическая логика, исправлены ошибки ввода и обработки граничных случаев. Дополнительные примеры и CSV-анализатор — учебные демонстрационные проекты.
