### 💳 Анализ банковских операций на C
[Исходный код](projects/transactions.c) · [Пример CSV-файла](projects/sample_transactions.csv)

Учебная консольная программа, которая читает транзакции из CSV-файла, проверяет строки, группирует расходы по категориям, считает суммы и выделяет операции от 10 000 рублей. Программа использует синтетические данные и не подключается к банковским системам.

**Технологии:** C, файловый ввод-вывод, структуры данных, алгоритмы обработки данных.

**Запуск (GCC):**

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic projects/transactions.c -o transactions
./transactions projects/sample_transactions.csv
```
