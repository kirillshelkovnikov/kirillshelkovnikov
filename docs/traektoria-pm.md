# Траектория ПМ

Учебный веб-проект: личный маршрут студента первого курса прикладной математики.

## Функции прототипа

- Учебный маршрут с темами, материалами лекций и объяснениями.
- Практические задания и тренажёр умножения матриц.
- Отслеживание прогресса по математическому анализу, алгебре, линейной алгебре, программированию и аналитической геометрии.

## Статус

Это описание по сохранённым материалам проекта. Исходный код пока не опубликован, поэтому ссылка не выдаётся за работающее веб-приложение. Для публикации приложения потребуется исходный код и проверка прав на внешние учебные материалы.
